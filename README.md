# washing-machine-controller-using-FSM-in-verilog
A washing machine controller designed using finite state machines in Verilog HDL

Overview :

This project focuses on designing a washing machine controller using a Finite State Machine (FSM) in Verilog HDL.

Objectives :

- Understand FSM-based digital system design.
- Implement control sequences using Verilog.
- Learn RTL design and simulation concepts.

Tools and Technologies :

- Verilog HDL
- Digital Electronics
- FSM Design
- Verilog Simulator (vivado)

Working Principle :

The controller uses defined states to manage the washing sequence. The state transitions depend on the implemented control inputs and conditions.

Project Files :

-Verilog source code
-Testbench
-Simulation waveform

- Improve input and output control.
